Important limitation

This tool is an educational triage tool. It identifies common warning signs but cannot definitively determine whether an email is malicious or safe.

Do not click suspicious links or open attachments merely to test them. Independently verify important messages using the organisation's official website, application or known contact information.

HOW IT WORKS

Transparent analysis

The analyser uses predefined cybersecurity indicators. There is no hidden AI model and no external service.

01

Inspect

The browser examines the email text, URLs, attachment references and available headers.

02

Score

Each detected warning sign contributes a defined number of points to the risk score.

03

Explain

Every detected indicator is displayed so the user can understand why it affected the result.

SCORING MODEL

Defined warning-sign weights

The score is deliberately explainable. These are warning-sign weights, not a probability that an email is malicious.
